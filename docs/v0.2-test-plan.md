## 2. 单元测试矩阵（T0）

### P1-1 list 别名 + ls 独立短列表（cli/mod.rs + 集成断言）

| 用例 | 断言 |
|---|---|
| `rewrite_argv(["li","foo"])` | 不重写（`li` 是已知命令，命中白名单） |
| `rewrite_argv(["ls"])` | `None`（`ls` 独立命令，白名单） |
| `rewrite_argv(["l",...])` | 不重写（`l` 从白名单移除 → 按裸词/未知处理，详见 P1-2） |

- `Cli::command().find_subcommand("li")` 存在、`find_subcommand("l")` 为 None、`find_subcommand("ls")` 存在
- ls 渲染（T1 断言输出列数）：`编号\t标签\t内容`，标签空格分隔、无标签 `-`、内容截断 40；与 list 的 `编号[\t时间]\t内容` 列式区分

### P1-2 默认分派（新纯函数 `classify_default(args: &[String]) -> Option<DefaultAction>`）

DefaultAction: `List` | `ShowId(String)` | `ShowUid(String)`；返回 `None` = 首参是已知命令/flag，不重写。

判定规则（定稿）：纯数字 → ShowId；带 `memos/` 前缀或裸词长度 ≥ 20 → ShowUid；其他词 → List；空参 → List。

| 入参 | 期望 |
|---|---|
| `[]` | `List`（TW `task` ≡ list） |
| `["3"]` | `ShowId("3")` |
| `["0"]` | `ShowId("0")`（走 resolve_id 报"编号 0 超出范围"，回归 P0-1） |
| `["i3HeAUTgvAyksy7FkhP6K3"]` | `ShowUid`（22 字符 base62） |
| `["memos/abc-123"]` | `ShowUid` |
| `["u5"]`（短非数字） | `List`（裸词 contains "u5"；短 uid 不识别，文档化） |
| `["foo"]` | `List`（裸词筛选） |
| `["+work"]` / `["-work"]` / `["/re/"]` / `["time.after:1w"]` | `List` |
| `["3","4"]` | `List`（多参数数字 = 裸词筛选，D2 推荐） |
| `["list"]` / `["li"]` / `["ls"]` / `["edit"]` / `["e"]` / `["+"]` / `["-"]` / `["tags"]` / `["ids"]` / `["export"]` / `["import"]` / `["tui"]` / `["config"]` / `["cfg"]` / `["version"]` / `["help"]` | `None` |
| `["-h"]` / `["-V"]` / `["--help"]` / `["--version"]` / `["--base"]` / `["--token"]` / `["--raw"]` | `None`（顶层 flag 不重写） |

### P1-5 `-tag` 首参（并入 `classify_default` 白名单检查，cli/mod.rs）

| 入参 | 期望 |
|---|---|
| `["-work"]` | `List`（注入 list 后 `-work` 成为 ExcludeTag） |
| `["-1"]` | 不重写 → clap 报 unknown flag（`-` 后数字非筛选，保持现状） |
| `["-h"]`/`["-V"]`/`["--raw"]` | `None`（防 `list -h` 误入） |

### P1-6 裸词筛选（api.rs `Filter::parse` + `matches`）

| 用例 | 断言 |
|---|---|
| `parse("foo")` | `Some(Contains("foo"))` |
| `parse("foo-bar")` | `Some(Contains("foo-bar"))`（连字符保留） |
| `parse("+foo")` / `parse("-foo")` / `parse("/foo/")` | 仍分别 Incl/Excl/Regex（前缀优先于裸词） |
| `parse("-1")` / `parse("-0x")` | 维持 `None`（现行为不回归） |
| `parse("")` / `parse("+")` / `parse("-")` / `parse("//")` | 维持 `None`（空标记不筛选） |
| contains 匹配：`memo "草稿-会议记录"` × `Contains("会议")` | true；`Contains("记录草")` 子串不连续 → false |
| contains 大小写：`Contains("BUDGET")` × "budget" | false（与 regex 一致，大小写敏感） |
| AND 组合：`Contains("草稿") + Incl("work")` | 仅 A 命中 |

### P2-2 时间筛选（新 `parse_smart_date(&str) -> Result<DateTime>`；`Filter::parse("time.after:X")`）

相对量（以测试片段固定 now 为基准，或函数注入基准时间以便确定性）：

| 输入 | 断言 |
|---|---|
| `1w` / `3d` / `2mo` / `1y` | now ± 对应时长（mo=30d、y=365d 文档化精度） |
| `today` / `yesterday` / `tomorrow` / `now` | 当天 00:00 / 昨日 00:00 / 明日 00:00 / 当前时刻 |
| `sow` / `som` / `soy` | 本周一 / 本月 1 日 / 本年 1 月 1 日 00:00 |
| `eow` / `eom` / `eoy` | 本周五 / 月末 / 年末 23:59:59 |
| `2026-09-01` / `2026-09-01T08:00:00Z` | 精确解析 |
| `banana` / 空串 | Err |
| `parse("time.after:1w")` | `Some(TimeAfter)`；`parse("time.after:")` | Err |
| `parse("time:1w")`（缺 op） | Err（本版不支持，文档化） |

匹配边界：`TimeBefore` 用 `<`（不含时刻相等），`TimeAfter` 用 `>`；含入问题对齐 TW `due.before`/`due.after` 语义，单测钉死。

### P2-1 筛选目标删除（api.rs `parse_delete_targets` 扩展）

构件：`expand_filter_targets(targets, memos) -> Vec<(label, uid)>`（新增，供删除与 ids 复用）。单元断言：

| targets | memos 集 | 期望 |
|---|---|---|
| `["+draft"]` | A/B/C（A 无 draft 标签） | 仅匹配 draft 的 uid；label 用正文预览 |
| `["-work"]` | A/B/C | B、C（排除 work） |
| `["/验收/"]` | A/B/C | 仅 C |
| `["+draft","3"]` | — | 筛选匹配 ∪ 编号 3，去重 |
| `["+nonexistent"]` | — | Err（零匹配防误删，退出非零） |
| `["+a","/b/","c","3"]` | — | 多筛选 AND 后与编号合并 |
| `["-y"]`/`["--force"]`/`["--confirm"]` | — | 不进入目标解析（flag 消费，现有行为不回归） |

## 7. 风险与豁免

- **clap 顶层 trailing args 与子命令共存**：若 `classify_default` 注入方案不可行（见修改计划 P1-2 实现风险），退回 `run()` 预处理重写 argv（现架构已如此），T0 分类函数不变，仅接入点不同——实现时确认，测试意图不受影响
- **uid 长度启发式**（≥20 字符）可能把超长裸词筛选误判为 uid 查看：罕见且下钻 `get` 失败会报 uid 不存在（快速自纠），文档化豁免
- **智能日期精度**：mo=30d/y=365d 与日历语义（如 `eom`）不同精度混用，单测钉死各输入期望值即可，不做完美日历库
- **live 测试的网络抖动**：T2 单条失败不连续重试（AGENTS.md 两次失败即反馈），报告环境而非盲目重跑
