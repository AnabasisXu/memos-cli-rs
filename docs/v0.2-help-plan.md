# memos-cli help 优化规划（v0.2.1）

- 日期: 2026-09-20
- 依据用户要求: ① help 全部改英文表述 ② 新增 `--alias` 展示别名（从 help 移出） ③ Commands 列表只用完整命令名（如用 `delete` 不用 `-`）
- 状态: ✅ 用户审核通过（2026-09-20，5 个确认点全部反馈）并已实施；代码 + 测试 + 文档同步完毕（见 §5 影响面）

## 1. 目标

1. `--help` 输出全英文（about、命令描述、选项描述）；命令列表只用**完整命令名**，不显示别名、不用符号命令名（`-` → `delete`、`+` → `add`）
2. 新增顶层 `memos-cli --alias`：打印全部命令别名映射（原分散在 help 的 `[alias: ...]` 信息集中于此）
3. 命令**行为不变**：`-`/`del`/`rm`、`+` 等别名继续可用，仅 help 展示层调整

## 2. 命令名调整

| 命令 | 现主名 | 新主名 | 别名（隐藏，--alias 展示） |
|---|---|---|---|
| 删除 | `-` | **`delete`** | `-`、`del`、`rm` |
| 新增 | `add`（已是） | `add` | `+` |
| 列表 | `list` | `list` | `li` |
| 编辑 | `edit` | `edit` | `e` |
| 配置 | `config` | `config` | `cfg` |
| 其他 | ls/tags/ids/export/import/tui/version/help | 不变 | 无 |

说明：
- `delete` 主名（TW 同 `task delete`）；`-` 降为隐藏别名——`memos-cli - 1`、`del 1`、`rm 1`、`delete 1` 全部继续可用
- clap 别名从 `visible_alias` 改为 `alias`（隐藏，help 不再显示 `[alias: ...]`）
- 完整命令表（help Commands 顺序建议）：`add list ls tags ids edit delete export import tui config version help`
- 白名单（默认分派）不变：含 `-`/`del`/`rm`/`+` 等所有别名，行为零变化

## 3. `--alias` 设计

- 顶层 flag：`memos-cli --alias`（无网络、无 token 依赖；同 `--version` 处理路径）
- 输出（英文，含默认命令提示）：

```
Aliases:
  list:   li
  add:    +
  delete: -, del, rm
  edit:   e
  config: cfg
```

- 与 `--help` 组合：`memos-cli --alias` 独立输出；`memos-cli --help --alias` 行为待定〔见 §6 确认点〕
- 别名信息源：硬编码表（与 clap 定义同步维护；或用 clap `Command::command()...` 反射？——硬编码简单可靠，规划选硬编码 + 单测断言与命令存在性一致）

## 4. help 预期输出（修改后，英文）

```
Unofficial usememos CLI + TUI

Usage: memos-cli [OPTIONS] [COMMAND]

Commands:
  add       Add a memo (use +tag for tags)
  list      List memos with all columns
  ls        Short list: id, tag, description
  tags      List all tags with counts
  ids       Output matching memo uids
  edit      Edit with $EDITOR
  delete    Delete memos
  export    Export all memos as TSV
  import    Import TSV from stdin
  tui       Interactive TUI mode
  config    View or write configuration
  version   Print version and build time
  help      Show help for a command

Options:
      --base <BASE>      Override server base URL
      --token <TOKEN>    Override access token
      --raw              Raw JSON output (global)
      --no-default       Skip default filters
      --alias            List command aliases
  -h, --help             Print help
  -V, --version          Print version
```

- Usage 从 `<COMMAND>` 变 `[COMMAND]`（可选，因默认分派）
- 各子命令 `--help`（如 `memos-cli delete --help`）描述同步英文

## 6. 待确认点（结论已记录）

1. `--alias` 输出格式：`command: alias` 对照表（推荐）还是每行 `alias -> command`？→ **前者**（`command: alias` 对照表）
2. `memos-cli --alias` 与 `--help`/其他 flag 组合时的行为（推荐：`--alias` 独立优先，其余照旧）→ **独立，不应该混用**：`--alias` 单独出现才输出；与其他 flag 组合报错（`--alias cannot be combined...`，退出非零）
3. 命令排序：`add list ls tags ids edit delete ...` 是否合适（建议按使用频率：add/list 靠前）→ **同意**
4. 子命令 `delete --help` 的 Usage 显示 `delete [TARGETS]...`（非 `-`）确认接受 → **接受**
5. 顶层 `about` 用 `Unofficial usememos CLI + TUI` 还是保留中文？→ **确认英文**
